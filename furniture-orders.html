Furniture Orders Pipeline

A scheduled pipeline that loads order data into PostgreSQL every day and keeps the reporting tables current.

Schedule
Runs daily
Built with
Kestra, Python, pandas, PostgreSQL
Output
Daily KPI tables

Objective

Reliable reporting tables behind a dashboard: new orders loaded on a schedule, with KPI tables refreshed and every run traceable.

Implementation

  • A daily Kestra flow that loads orders into PostgreSQL
  • KPI tables for orders, revenue and delivery delays
  • Run logging and reproducible outputs for easy troubleshooting
