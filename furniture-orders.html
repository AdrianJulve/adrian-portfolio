Furniture Orders Pipeline

A scheduled data pipeline that loads furniture order data into PostgreSQL every day and keeps a set of reporting tables up to date.

Type

Overview

This project covers the part of reporting that happens before the dashboard: a job that runs on a schedule, loads new orders and refreshes the tables a report reads from.

What I built

  • A Kestra flow that runs daily, ingests order data with Python and pandas, and loads it into PostgreSQL.
  • Daily KPI tables for orders, revenue and delivery delays, ready for reporting and trend analysis.
  • Run logging and reproducible outputs, so any day's run can be traced and repeated when something looks wrong.

Skills

Workflow orchestration with Kestra, data loading and transformation in Python and pandas, relational modelling in PostgreSQL, and designing pipelines that are easy to troubleshoot.
